# Instruções e skills

Plano Básico · 1h · Aula ao vivo no Google Meet

## Objetivo

Padronizar uma tarefa repetitiva com instruções.

## O que você aprende

O que é uma skill, como organizar instruções reutilizáveis e quando aplicar. CLI e GitHub como conceitos.

## Conteúdo de estudo

Uma skill reúne instruções e recursos para repetir um procedimento. Defina quando usar, quais dados receber, quais etapas executar e como conferir a saída. No básico, o foco é entender e padronizar a tarefa. CLI e GitHub entram como conceitos; a construção de aplicações pertence ao avançado.

## Prática orientada

1. Defina a entrada e o resultado esperado com o professor.
2. Execute a tarefa com os dados do projeto e registre o resultado.
3. Confira uma amostra, corrija os pontos necessários e explique a solução.

## Entrega e conferência

Padronizar uma tarefa repetitiva com instruções. A entrega é conferida por demonstração, revisão dos dados e explicação do aluno.
