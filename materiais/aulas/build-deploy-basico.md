# Plano Básico · Aula 14: Build e deploy: publique sua primeira página

Duração presencial planejada: 90 minutos. Videoaula em preparação.

## Objetivo da aula

Distinguir preparação da aplicação e publicação na internet.

## Conteúdo de estudo

Build prepara arquivos para distribuição quando a tecnologia exige essa etapa. Deploy publica uma versão em um ambiente acessível. Uma página HTML simples pode ser publicada sem build. O GitHub Pages serve arquivos estáticos; ele não executa um servidor de login ou banco de dados. Publique a página de estudo, espere a execução finalizar e confira a URL. Compare a versão publicada com o commit correspondente.

## Demonstração presencial

Publicar uma página de exemplo no GitHub Pages e acompanhar a execução.

## Prática guiada

Publicar a própria página e testar dois links em computador e celular.

## Sua entrega

URL pública e registro do commit da publicação.

## Como conferir

A página publicada corresponde ao código e não depende de arquivos locais?
