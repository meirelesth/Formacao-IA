# Sistema funcional

Plano Avançado · 2h · Aula ao vivo no Google Meet

## Objetivo

Construir um sistema simples com fluxo completo.

## O que você aprende

Cadastro, busca, filtros e status. Validação de entradas e telas para acompanhar a operação.

## Conteúdo de estudo

Implemente um caminho completo: cadastro, listagem, busca e atualização de status. Defina o que acontece com entradas inválidas e resultados vazios. Use a mesma base do projeto e confira a persistência dos registros. O sistema é um MVP de escopo definido, preparado para estudo e evolução.

## Prática orientada

1. Defina a entrada e o resultado esperado com o professor.
2. Execute a tarefa com os dados do projeto e registre o resultado.
3. Confira uma amostra, corrija os pontos necessários e explique a solução.

## Entrega e conferência

Construir um sistema simples com fluxo completo. A entrega é conferida por demonstração, revisão dos dados e explicação do aluno.
