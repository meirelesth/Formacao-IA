# Plano Avançado · Aula 08: Dependências, build e integração contínua

Duração presencial planejada: 90 minutos. Videoaula em preparação.

## Objetivo da aula

Preparar uma versão reproduzível e verificar mudanças automaticamente.

## Conteúdo de estudo

Dependências, arquivos de trava e comandos de build influenciam a reprodução. Registre versões e use os scripts do projeto. Integração contínua executa verificações em mudanças; deploy distribui uma versão. Um build aprovado não prova que a interface funciona. Acrescente um teste útil e uma verificação do percurso principal. Não publique um projeto que apenas funciona na máquina do autor.

## Demonstração presencial

Executar instalação reproduzível, teste e build; mostrar uma execução que falha.

## Prática guiada

Criar um fluxo de verificação do projeto e corrigir uma falha deliberada.

## Sua entrega

Pipeline com evidências de falha e sucesso.

## Como conferir

Um clone novo consegue gerar a mesma versão com os comandos documentados?
