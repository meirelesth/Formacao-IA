# Plano Avançado · Aula 02: Codex CLI e Claude Code na prática

Duração presencial planejada: 90 minutos. Videoaula em preparação.

## Objetivo da aula

Usar agentes para inspecionar, alterar e testar um projeto.

## Conteúdo de estudo

Codex CLI e Claude Code trabalham com arquivos, comandos e ferramentas conforme a configuração. Autenticação pelo produto e uso de API podem ter cobranças e limites diferentes. Defina uma tarefa pequena, peça inspeção, revise o plano e acompanhe o diff. Permissões amplas não substituem revisão. Escolha apenas um agente por alteração para evitar edições concorrentes na mesma área.

## Demonstração presencial

Pedir a cada ferramenta a explicação de um projeto e executar uma alteração controlada.

## Prática guiada

Adicionar uma função pequena, revisar arquivos modificados e executar a verificação.

## Sua entrega

Diff revisado, verificação registrada e commit da alteração.

## Como conferir

O aluno explica quais arquivos mudaram e como confirmou o comportamento?
