# Plano Básico · Aula 11: Como criar sua conta e seu primeiro repositório GitHub

Duração presencial planejada: 90 minutos. Videoaula em preparação.

## Objetivo da aula

Organizar um projeto em um repositório com acesso adequado.

## Conteúdo de estudo

Git é o sistema de controle de versões. GitHub hospeda repositórios e permite colaboração. Crie sua conta pelo site oficial, confirme o e-mail e configure autenticação em duas etapas. Escolha a visibilidade antes de enviar arquivos. O README explica o projeto. Não publique senhas, dados pessoais ou chaves. O repositório de estudo conterá apenas o material criado para o curso e exemplos fictícios.

## Demonstração presencial

Criar um repositório de demonstração, um README e mostrar configurações de visibilidade.

## Prática guiada

Criar a própria conta ou usar a conta existente e iniciar um repositório de estudo.

## Sua entrega

Repositório com README, descrição e visibilidade revisada.

## Como conferir

O aluno diferencia Git de GitHub e localiza a visibilidade e o histórico?
