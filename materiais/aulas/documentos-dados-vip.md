# Documentos e dados úteis

Plano Básico · 1h · Aula ao vivo no Google Meet

## Objetivo

Preparar uma base de estudo organizada.

## O que você aprende

Resumo, extração, classificação e estruturação de informações. Cuidados com dados e validação.

## Conteúdo de estudo

Antes de pedir uma análise, confira cabeçalhos, datas, valores e campos vazios. Separe os fatos do documento das interpretações produzidas pela IA. Solicite uma tabela com origem e resultado e valide uma amostra manualmente. A base organizada será usada para construir os indicadores.

## Prática orientada

1. Defina a entrada e o resultado esperado com o professor.
2. Execute a tarefa com os dados do projeto e registre o resultado.
3. Confira uma amostra, corrija os pontos necessários e explique a solução.

## Entrega e conferência

Preparar uma base de estudo organizada. A entrega é conferida por demonstração, revisão dos dados e explicação do aluno.
