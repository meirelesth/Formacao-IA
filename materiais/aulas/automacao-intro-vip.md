# Primeira automação com n8n

Plano Básico · 2h · Aula ao vivo no Google Meet

## Objetivo

Automatizar uma rotina com dados de estudo.

## O que você aprende

Gatilho, etapas, transformação de dados e teste. Construção a partir de um modelo simples preparado.

## Conteúdo de estudo

Uma automação combina um gatilho, etapas de tratamento e uma saída. Comece com um modelo simples no n8n e dados fictícios. Confira a entrada de cada etapa e execute o fluxo manualmente antes de definir uma rotina. Registre o resultado esperado e o que fazer quando faltar um dado.

## Prática orientada

1. Defina a entrada e o resultado esperado com o professor.
2. Execute a tarefa com os dados do projeto e registre o resultado.
3. Confira uma amostra, corrija os pontos necessários e explique a solução.

## Entrega e conferência

Automatizar uma rotina com dados de estudo. A entrega é conferida por demonstração, revisão dos dados e explicação do aluno.
