# Plano Avançado · Aula 09: APIs, HTTP, JSON e autenticação

Duração presencial planejada: 90 minutos. Videoaula em preparação.

## Objetivo da aula

Consultar um serviço com dados estruturados e acesso adequado.

## Conteúdo de estudo

APIs expõem operações. HTTP informa método, URL, cabeçalhos, corpo e resposta; JSON organiza os dados. Status como 401, 403, 429 e 500 indicam problemas diferentes. Chaves e tokens ficam em credenciais ou variáveis de ambiente, não no frontend. Primeiro pratique com uma API de laboratório. Defina contrato, timeout, limites e como tratar respostas inválidas antes de conectar um serviço real.

## Demonstração presencial

Consultar uma API de teste e analisar respostas válidas, ausência de autorização e limite de uso.

## Prática guiada

Documentar uma chamada e validar os campos retornados.

## Sua entrega

Contrato da integração e chamada de laboratório reproduzível.

## Como conferir

A solução distingue erro de acesso, limite e resposta inválida?
