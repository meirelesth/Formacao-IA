# Git e GitHub sem complicação

Plano Avançado · 2h · Aula ao vivo no Google Meet

## Objetivo

Versionar o projeto no GitHub.

## O que você aprende

Conta, repositório, commits, branches, diferenças e recuperação de versões. Revisão antes de integrar.

## Conteúdo de estudo

Git registra as mudanças e GitHub permite hospedar o repositório. Faça commits com mensagens claras e confira as diferenças antes de salvar. Use uma branch para uma alteração separada e revise antes de integrar. Saiba localizar uma versão anterior e explique o que mudou no projeto.

## Prática orientada

1. Defina a entrada e o resultado esperado com o professor.
2. Execute a tarefa com os dados do projeto e registre o resultado.
3. Confira uma amostra, corrija os pontos necessários e explique a solução.

## Entrega e conferência

Versionar o projeto no GitHub. A entrega é conferida por demonstração, revisão dos dados e explicação do aluno.
